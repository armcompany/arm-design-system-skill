# Design Owner Product Skills

[![skills.sh](https://skills.sh/b/armcompany/arm-design-system-skill)](https://www.skills.sh/armcompany/arm-design-system-skill)

Skills for product design, design system engineering, and visual QA.

## Skills

### design-system-engineering

Reusable guidance for creating, consuming, auditing, and evolving tokenized product Design Systems.

```sh
npx skills add armcompany/arm-design-system-skill --skill design-system-engineering
```

### design-engineering

Product design end-to-end: from requirements to implementation-ready screens with visual QA.

```sh
npx skills add armcompany/arm-design-system-skill --skill design-engineering
```

Both skills are framework-agnostic. Platform architecture skills remain responsible for framework-specific implementation details.
